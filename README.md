# CasaForma Interiors

A responsive interior design website built using React and Vite. The website showcases interior design projects, services, design styles, materials, and interactive features.

## Live Website

https://interior-design-website-1cq6t53bu-komali5.vercel.app/

## Technologies Used

- React.js
- Vite
- JavaScript
- HTML and JSX
- CSS
- Lucide React

## Features

- Responsive navigation and layout
- Interior project search, filtering, and sorting
- Project details and saved-project wishlist
- Image gallery and before-and-after comparison
- Interior design style quiz
- Cost estimation calculator
- Materials and finishes catalogue
- FAQ accordion
- Consultation and project enquiry forms
- Design process and team sections

## Run Locally

1. Install Node.js.
2. Clone or download this repository.
3. Open the project folder in a terminal.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the local URL displayed in the terminal.

## Demo Notice

Project examples, testimonials, contact details, and cost estimates are demonstration content and do not represent verified real clients or quotations.

## Limitations

The website is currently frontend-focused. Form submissions do not represent real enquiry delivery unless a backend or form service is connected.
